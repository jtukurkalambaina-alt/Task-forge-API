# TaskForge API

OpenAPI 3.0.3 contract for the TaskForge item management API.

## Contents

- `openapi.yaml` - API specification for listing, creating, reading, replacing, partially updating, and deleting items.

## How to use

You can import `openapi.yaml` into tools like Swagger UI, Redoc, Postman, Stoplight, Prism, or OpenAPI Generator for documentation, mock servers, validation, testing, and client SDK generation.
